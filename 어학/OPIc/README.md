# OPIc

- 목표 등급: **IM2** (달성 후 IH로 상향)
- 기간: 8주
- 하루 30분

## 하루 루틴

| 시간 | 내용 |
|---|---|
| 5분 | 어제 스크립트를 키워드만 보고 복습 |
| 15분 | 오늘의 주제 스크립트 쓰기 (영어 5~8문장) |
| 10분 | 소리 내어 말하고 녹음해서 한 번 듣기 |

## 8주 로드맵

- **1~2주**: 시험 구조 파악, Survey 선택 전략, 자기소개와 기본 표현
- **3~5주**: 주제당 묘사·습관·과거 경험 3종 답변 (5~6개 주제)
- **6~7주**: 롤플레이, 돌발 질문, 스크립트 없이 말하기
- **8주**: 모의고사 2~3회 후 시험 응시
