1. 15분 생각해도 모르면 **풀이 보기 OK**, 대신 아무것도 안 보고 **다시 직접 구현**

3. 풀이 후 **시간복잡도를 반드시 말로** 적기 (입력 크기 N → 허용 복잡도: 10^5이면 O(N log N), 10^3이면 O(N²))
4. 틀린 문제는 3일 뒤 다시 풀기 (오답 노트)

## 신호 → 알고리즘 치트시트 (직접 채우기)

| 문제에서 보이는 신호 | 먼저 떠올릴 것 |
|---|---|
| 최단 거리, 최소 횟수 (가중치 없음) | BFS |
| 가중치 있는 최단 경로 | 다익스트라 |
| "모든 경우" + N이 작음(≤ 20) | 완전탐색 / 백트래킹 |
| 정렬된 배열, 최댓값의 최솟값 | 이분 탐색 |
| 구간 합 반복 질의 | 누적합 |
| 부분 문제가 겹침 | DP |
| 연결 여부, 그룹 | Union-Find / DFS |
