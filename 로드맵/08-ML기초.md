# 08. ML 기초 · 평가지표 로드맵 (14일)

- **목표**: 모델 학습의 기본 흐름과 **평가지표를 상황에 맞게 고르고 해석**하는 힘 (LLM 평가의 밑바탕)

## Day별 계획

- [ ] **Day 1** — ML 큰 그림 + 선형회귀와 MSE
  - **ML 큰 그림**: 지도/비지도/강화, train/validation/test 분리, **데이터 누수(leakage)**
    확인: 검증 세트와 테스트 세트를 왜 따로 두나?
  - **선형회귀와 MSE**: 직접 구현 → `sklearn.LinearRegression`과 비교
- [ ] **Day 2** — 로지스틱 회귀와 크로스 엔트로피 + 첫 프로젝트
  - **로지스틱 회귀와 크로스 엔트로피**: 시그모이드, 결정 경계
  - **첫 프로젝트**: 정형 데이터(예: 타이타닉)로 `Pipeline`(전처리 + 모델) 구성
- [ ] **Day 3** — 과적합과 과소적합 + 정규화 (L1/L2)
  - **과적합과 과소적합**: 학습 곡선(learning curve) 그리기, 편향-분산
    확인: train 점수는 높고 val 점수는 낮을 때 할 수 있는 일 4가지
  - **정규화 (L1/L2)**: Ridge/Lasso 비교, 가중치 크기 변화 plot
- [ ] **Day 4** — 복습 + 혼동행렬
  - **복습**: 위 데이터에서 과적합을 일부러 만들고 해결 과정 기록
  - **혼동행렬**: TP/FP/TN/FN, **Accuracy의 함정**(불균형 데이터)
- [ ] **Day 5** — Precision / Recall / F1 + ROC-AUC vs PR-AUC
  - **Precision / Recall / F1**: 임계값(threshold)을 움직이며 변화 관찰
    확인: 스팸 필터와 암 진단에서 각각 어느 지표를 중시하나?
  - **ROC-AUC vs PR-AUC**: 곡선 직접 그리기, 불균형일 때 PR-AUC가 나은 이유
- [ ] **Day 6** — 교차검증과 하이퍼파라미터 탐색 + 불균형 데이터
  - **교차검증과 하이퍼파라미터 탐색**: K-Fold, Stratified, `GridSearchCV`/Optuna
  - **불균형 데이터**: class weight, 오버/언더샘플링, 임계값 조정
- [ ] **Day 7** — 회귀 지표 + 복습 퀴즈
  - **회귀 지표**: MAE, RMSE, R², 이상치에 대한 민감도 차이
  - **복습 퀴즈**: "이 상황엔 어떤 지표?" 시나리오 10개를 직접 만들어 답하기
- [ ] **Day 8** — 결정 트리 + 랜덤포레스트 (배깅)
  - **결정 트리**: 지니/엔트로피, 시각화(`plot_tree`)
  - **랜덤포레스트 (배깅)**: 분산을 줄이는 원리, 특성 중요도
- [ ] **Day 9** — 부스팅 + k-NN, SVM 개념
  - **부스팅**: XGBoost/LightGBM 학습, 배깅과의 차이
  - **k-NN, SVM 개념**: k-NN은 "검색"과 같은 구조라는 연결 지점 정리
- [ ] **Day 10** — 클러스터링 + 차원 축소
  - **클러스터링**: k-means, 실루엣 점수, k 고르기
  - **차원 축소**: PCA, t-SNE/UMAP으로 임베딩 시각화
- [ ] **Day 11** — 특성 공학 + TF-IDF와 BM25
  - **특성 공학**: 결측치, 범주형 인코딩, 스케일링, 누수 점검
  - **TF-IDF와 BM25**: 직접 구현해서 `rank_bm25`와 결과 비교
- [ ] **Day 12** — 임베딩과 근사 최근접 탐색 (ANN) + 검색 평가지표
  - **임베딩과 근사 최근접 탐색 (ANN)**: 정확 검색 vs HNSW, 속도·정확도 트레이드오프
  - **검색 평가지표**: Recall@k, MRR, nDCG 계산 함수 직접 작성
    연결: RAG 리트리버 평가에 그대로 쓰는 지표
- [ ] **Day 13** — 오류 분석(오답노트) + 실험 관리
  - **오류 분석(오답노트)**: 틀린 샘플을 유형별로 분류하는 습관, 오류 유형 표 만들기
  - **실험 관리**: 시드 고정, 재현성, MLflow 또는 W&B 기초
- [ ] **Day 14** — 미니 프로젝트 정리 + 정리 시트
  - **미니 프로젝트 정리**: 데이터 → 모델 → 지표 해석 → 개선까지 README로
  - **정리 시트**: "상황별 지표 선택표" 1장 완성
