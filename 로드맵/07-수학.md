## Day별 계획

- [ ] **Day 1** — 벡터, 내적, 노름 + 행렬 곱셈과 shape
  - **벡터, 내적, 노름**: 내적의 기하학적 의미, L1/L2 노름
    연결: 코사인 유사도 = 정규화한 내적 (RAG 검색의 핵심)
  - **행렬 곱셈과 shape**: `(m×n)·(n×p)=(m×p)`, numpy `@`, 브로드캐스팅
    확인: 임베딩 행렬 `(N×d)`와 쿼리 `(d,)`의 곱이 무엇을 계산하나?
- [ ] **Day 2** — 선형 변환 + 역행렬, 행렬식, 랭크
  - **선형 변환**: 3B1B 영상 시청, 회전/스케일 행렬을 점에 적용해 plot
  - **역행렬, 행렬식, 랭크**: 연립방정식, 역행렬이 없는 경우
- [ ] **Day 3** — 고유값·고유벡터 + SVD와 PCA 직관
  - **고유값·고유벡터**: `np.linalg.eig`, "방향이 안 바뀌는 벡터"
  - **SVD와 PCA 직관**: 데이터 공분산 → 주성분, 2차원 데이터 시각화
- [ ] **Day 4** — 복습 + 미니 + 미분과 편미분
  - **복습 + 미니**: numpy만으로 **코사인 유사도 검색기** 구현 (문서 벡터 1000개에서 top-k)
  - **미분과 편미분**: 수치 미분으로 `f'(x)` 근사해서 해석적 미분과 비교
- [ ] **Day 5** — 연쇄법칙 (chain rule) + 그래디언트
  - **연쇄법칙 (chain rule)**: 합성함수 미분, 역전파의 수학적 뿌리
  - **그래디언트**: 벡터 함수의 기울기, 등고선 그림에 그래디언트 화살표
- [ ] **Day 6** — 경사하강법 구현 + SGD, 모멘텀, Adam 직관
  - **경사하강법 구현**: numpy로 선형회귀를 경사하강법으로 학습
    확인: 학습률이 너무 크면/작으면 어떻게 되나?
  - **SGD, 모멘텀, Adam 직관**: 같은 함수에서 옵티마이저별 수렴 경로 비교
- [ ] **Day 7** — 역전파 손계산 + 복습 + 미니
  - **역전파 손계산**: 2층 신경망 1회 forward/backward를 종이로 계산 후 코드로 검증
  - **복습 + 미니**: Karpathy *micrograd* 따라 만들기 (자동미분 엔진)
- [ ] **Day 8** — 확률 기초와 조건부 확률 + 베이즈 정리
  - **확률 기초와 조건부 확률**: 곱셈 법칙, 전확률 공식
  - **베이즈 정리**: 의료 검사 예제, 나이브 베이즈 스팸 필터 간단 구현
- [ ] **Day 9** — 확률변수, 기댓값, 분산 + 주요 분포
  - **확률변수, 기댓값, 분산**: 시뮬레이션으로 기댓값 확인
  - **주요 분포**: 베르누이, 이항, 정규, 카테고리 분포 / 소프트맥스는 어떤 분포를 만드나?
- [ ] **Day 10** — 결합·독립·공분산·상관 + 큰 수의 법칙, 중심극한정리
  - **결합·독립·공분산·상관**: 상관계수와 인과관계의 차이
  - **큰 수의 법칙, 중심극한정리**: 시뮬레이션으로 표본평균 분포 그리기
- [ ] **Day 11** — 복습 + 최대우도추정 (MLE)
  - **복습**: 확률 개념 퀴즈 10개 만들어서 스스로 풀기
  - **최대우도추정 (MLE)**: 동전 던지기 예제, "MSE는 가우시안 가정의 MLE"
- [ ] **Day 12** — MAP와 정규화 + 가설검정, p-value, 신뢰구간
  - **MAP와 정규화**: 사전분포 ↔ L2 정규화의 관계 (직관만)
  - **가설검정, p-value, 신뢰구간**: A/B 테스트 예제, 평가 점수 차이가 유의미한지
- [ ] **Day 13** — 엔트로피와 크로스 엔트로피 + KL divergence, 로그 확률
  - **엔트로피와 크로스 엔트로피**: 분류 손실함수가 왜 크로스 엔트로피인가
  - **KL divergence, 로그 확률**: `log_softmax`, 수치 안정성(logsumexp)
- [ ] **Day 14** — 부트스트랩 + 정리 시트
  - **부트스트랩**: RAG 평가 점수 2개(개선 전/후)의 차이에 **부트스트랩 신뢰구간** 구하기
    연결: "정답률 62% → 78%"가 우연이 아님을 보이는 방법
  - **정리 시트**: 이 로드맵의 핵심 공식 1장 요약 + 각 공식이 AI 어디에 쓰이는지 연결
