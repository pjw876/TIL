## ① 자료형과 mutable/immutable

### 배운 것
- `id()`와 `is`를 몰랐는데 알게 됨
  - `id(x)`: 객체의 고유 번호. 같은 객체면 같은 번호
  - `a is b`: 같은 **객체**인지 비교 (`id(a) == id(b)`와 같음)
  - `a == b`: **값**이 같은지 비교
  - `b = a`는 복사가 아니라 같은 객체에 이름을 하나 더 붙이는 것 → `b`를 바꾸면 `a`도 바뀜
  - `a.copy()`는 값이 같은 새 객체 → `a is c`는 `False`, `a == c`는 `True`
  - `is`는 보통 `None` 비교에만 사용 (`if x is None`)
- mutable / immutable
  - **mutable**(list, dict, set): 만든 뒤 그 객체를 **제자리에서 고칠 수 있음** (화이트보드)
  - **immutable**(int, str, tuple, bool, None): 고칠 수 없음. 바꾸려면 **새 객체를 만들고 이름만 옮김** (인쇄물)
  - mutable을 공유하면 한쪽이 고칠 때 다른 쪽도 영향을 받음, immutable은 공유해도 안전

  ```python
  a = [1, 2]; b = a
  b.append(3)          # 같은 객체를 고침
  print(a, a is b)     # [1, 2, 3] True

  s = "hi"; t = s
  t = t + "!"          # 새 객체를 만들고 t가 그쪽으로 이동
  print(s, t, s is t)  # hi hi! False
  ```
- `=` / 얕은 복사 / 깊은 복사
  - 리스트의 각 칸은 객체를 직접 품는 게 아니라 객체를 **가리키는 화살표**

  | | 겉(바깥 리스트) | 안쪽 객체 |
  |---|---|---|
  | `b = a` | 같은 객체 (이름만 추가) | 같은 객체 |
  | 얕은 복사 (`a.copy()`, `a[:]`, `list(a)`) | 새로 만듦 | **공유** |
  | 깊은 복사 (`copy.deepcopy(a)`) | 새로 만듦 | 전부 새로 만듦 |

  - 얕은 복사에서 **겉을 바꾸면**(추가/삭제/칸 교체 `c[1] = ..`) 원본은 그대로. 내 칸의 화살표만 바뀌기 때문
  - **안쪽을 고치면**(`c[0].append(..)`) 원본도 같이 바뀜. 같은 객체를 함께 가리키기 때문
  - 안쪽이 숫자/문자열 같은 immutable이면 얕은 복사로 충분

### 막혔던 점 / 해결
- `b = a`가 얕은 복사인 줄 헷갈림 → 복사가 아니라 이름표 추가. 얕은 복사는 `copy()`처럼 겉 객체를 새로 만드는 것
- 얕은 복사인데 왜 칸을 교체하면 원본이 안 바뀌나 → 공유하는 건 칸이 가리키는 객체이고, 칸(화살표) 자체는 각자 가짐
- 함정 예: `[[0] * 3] * 3`은 같은 안쪽 리스트를 3번 가리킴 → `[[0] * 3 for _ in range(3)]`로 만들어야 함
