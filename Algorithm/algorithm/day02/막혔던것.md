# Day 2 · 답을 물어본 문제 기록 (`stack_practice.py`)

> 막혀서 답이나 힌트를 본 문제. 3일 뒤에 **안 보고 다시** 풀어 보기 (오답 노트).

## 1-2 `top_of` — 맨 위 값 보기 (빈 스택이면 None)

```python
def top_of(stack):
    if not stack:
        return None
    return stack[-1]
```
- `stack[-1]`은 맨 끝(=맨 위)을 **지우지 않고 보기만** 함. `pop()`은 꺼내면서 지움
- 빈 스택에 `stack[-1]` 하면 `IndexError: list index out of range` → 먼저 `if not stack`으로 확인
- `not stack`은 비었으면 `True` (`[]`은 False 취급, 원소가 있으면 True 취급되는 list의 성질)
- 한 줄 버전: `return stack[-1] if stack else None`

## 1-3 `pop_two` — 맨 위부터 2개 꺼내기

```python
def pop_two(stack):
    a = stack.pop()
    b = stack.pop()
    return (a, b)
```
- `pop()`은 맨 위를 **꺼내서 지우고 그 값을 반환** → 두 번 부르면 두 번째 값이 나옴
- `[1, 2, 3]`에서 먼저 꺼낸 것은 3, 다음은 2 → `(3, 2)` (나중에 넣은 게 먼저 나옴)
- `pop()`한 값을 변수에 담지 않으면 그 값은 사라짐
- 한 줄 버전: `return (stack.pop(), stack.pop())` (튜플 안 왼쪽부터 차례로 실행되어 같은 결과)
- 원본 `stack`도 2개 줄어든 채로 바뀜 (`pop`은 list를 직접 고침)

## 2 `reverse_str` — 스택으로 문자열 뒤집기

**내가 쓴 것 (틀림)**
```python
str = list(s)
stack = [str.pop() for _ in str]
return "".join(stack)
```
- `'abc'` → `'cb'`, `'hello'` → `'oll'` (일부 글자가 빠짐)
- 원인: `for _ in str`가 **돌고 있는 list를 `pop()`으로 동시에 지움** → 반복이 중간에 끝남

**고친 것**
```python
chars = list(s)
stack = [chars.pop() for _ in range(len(chars))]
return "".join(stack)
```
- `range(len(chars))`는 **시작할 때 한 번만** 계산돼 횟수가 고정됨 → 안에서 list가 줄어도 안전
- `while` 버전 (덜 헷갈림): `stack = list(s)` → `out = ""` → `while stack: out += stack.pop()`

**배운 점**
- 문자열은 immutable이라 `s.pop()` 없음 (`AttributeError`) → `list(s)`로 list로 바꿔서 사용
- **돌고 있는 list를 동시에 고치지 말기** (원소를 지우면 반만 돎)
- 변수 이름으로 내장 이름(`str`, `list`, `dict`, `set`, `sum`, `max`, `min`, `len`, `input`) 쓰지 않기
- 결과가 list면 `"".join(...)`으로 문자열로 합치기

## 4 `is_valid` — 올바른 괄호

**내가 쓴 것 (틀림) ①**: `)`가 왔는데 스택이 비어 있으면 `IndexError`
```python
elif stack[-1] == "(" and ch == ")":
    stack.pop()
```
- 빈 스택에 `stack[-1]` → `IndexError`. 에러만 피하려고 `stack and ...`로 바꾸면 짝 없는 `)`가 **무시**돼서 `"())"`가 `True`로 나옴

**내가 쓴 것 (틀림) ②**: `return`이 함수를 끝내 버림
```python
elif ch == ")":
    return False if not stack else stack.pop()
```
- 스택이 안 비었을 때도 `return stack.pop()` → 함수가 `'('`를 돌려주고 끝남 (`"()()"` → `'('`)

**답**
```python
def is_valid(s):
    stack = []
    for ch in s:
        if ch == "(":
            stack.append(ch)
        else:                       # ch == ")"
            if not stack:
                return False        # 짝 없는 ')' → 바로 끝
            stack.pop()             # 짝 맞춤 (return 없음 → 다음 글자로)
    return not stack                # 남았으면 짝 없는 '(' → False, 비었으면 True
```

**배운 점**
- `return`은 값을 만드는 게 아니라 **함수를 즉시 끝내는** 명령 → 끝내고 싶을 때만 씀
- `)`는 두 경우로 나눔: **비었으면 `return False`**, 아니면 `pop()`만
- 스택에는 `(`만 쌓으니 `stack[-1] == "("` 확인은 불필요
- 문자열은 `list(s)` 없이 `for ch in s:`로 바로 돌 수 있음
- `return False if stack else True` = `return not stack`

## 헷갈렸던 개념 메모

- **"지운다"보다 "넣는다"로 생각 뒤집기** (같은 숫자는 싫어): 같으면 `pop` 후 `append`는 지웠다 다시 넣는 돌아가는 구조. 조건을 뒤집어 **"다를 때만 `append`"** 하면 `pop`이 필요 없고 더 단순함. 막히면 "반대로 하면 더 간단한가?"를 먼저 생각해 보기
