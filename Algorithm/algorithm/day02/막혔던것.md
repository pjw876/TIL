## 2-2 `score_of` — 없으면 0 반환

**내가 쓴 것 (틀림)**
```python
return d.get(d, name)
```
- `d.get(키, 기본값)`의 자리를 헷갈림. `d`는 이미 `d.get`의 앞에 있어서 괄호 안에 또 쓸 필요가 없음

**답**
```python
return d.get(name, 0)
```
- 첫 번째 자리 = 찾을 키(`name`), 두 번째 자리 = 없을 때 돌려줄 값(`0`)

## 2-3 `set_score` — 추가/수정 후 반환

```python
d[name] = score
return d
```
- `d[키] = 값`은 키가 없으면 **추가**, 있으면 **수정**
- 대입(`=`)은 값을 반환하지 않으므로 `return d[name] = score`는 문법 에러 → `return d`를 따로 써야 함

## 2-5 `total_of_pairs` — 같은 위치끼리 곱해서 합

```python
return sum(x * y for x, y in zip(a, b))
```
- `zip(a, b)` → `(1,4), (2,5), (3,6)` / 곱 → `4, 10, 18` / `sum` → `32`
- 괄호 안은 제너레이터 표현식 (리스트를 만들지 않고 하나씩 더함)
- 빈 입력이면 `sum`이 `0`을 반환

같은 뜻의 for문
```python
total = 0
for x, y in zip(a, b):
    total += x * y
return total
```

## 3-2 `count_of` — 글자가 몇 번 나오나

```python
return Counter(s)[ch]
```
- `Counter(s)`가 글자별 횟수를 세고, `[ch]`로 그 글자의 횟수를 꺼냄
- 없는 글자는 에러 없이 `0` (`dict`의 `d[key]`는 `KeyError`)

## 3-3 `top_char` — 가장 많이 나온 글자 1개

```python
return Counter(s).most_common(1)[0][0]
```
- `most_common(1)` → `[('l', 2)]` (list 안의 tuple)
- `[0]` → `('l', 2)` (첫 번째 tuple), 다시 `[0]` → `'l'` (글자만)
- 횟수까지 필요하면 `[0]`만 쓰면 `('l', 2)`
- 동점이면 먼저 나온 글자가 앞에 옴

## 3-4 `left_over` — 참가자 중 완주 못 한 1명

```python
return list(Counter(participant) - Counter(completion))[0]
```
- `Counter(["a","b","b"]) - Counter(["b","a"])` → `Counter({'b': 1})` (0 이하는 사라지고 남은 것만)
- `list(Counter)`는 **키 목록**을 줌 → `['b']` → `[0]`으로 이름 꺼내기
- 동명이인(`["m","m","n"]` vs `["n","m"]` → `"m"`)도 횟수로 세니까 처리됨
- 이름 + 횟수까지 필요하면 `most_common(1)[0]`
- "완주하지 못한 선수" 문제의 핵심 풀이 (O(n))

## 4-1 `index_by_point` — 좌표를 키로 하는 dict

```python
d = {}
for x, y, name in points:
    d[(x, y)] = name
return d
```
- `for x, y, name in points`: `(x, y, 이름)` tuple을 3개로 풀어서 받음 (언패킹)
- 키는 `(x, y)` tuple → immutable이라 가능. `[x, y]`(list)는 `TypeError: unhashable type: 'list'`
- 한 줄 버전 (dict 컴프리헨션): `return {(x, y): name for x, y, name in points}`

## 5 `two_sum` — 합이 target인 두 수의 인덱스

```python
seen = {}
for i, x in enumerate(arr):
    if target - x in seen:
        return [seen[target - x], i]
    seen[x] = i
return None
```
- `seen`은 `{값: 인덱스}`. 지나온 값을 기록해 두는 곳
- 현재 `x`의 짝은 `target - x` → 이미 `seen`에 있으면 정답 (`seen[짝]`이 앞 인덱스, `i`가 뒤 인덱스라 `i`가 항상 더 큼)
- **확인 먼저, 저장은 나중에**: 저장을 먼저 하면 `x` 자신을 짝으로 잡을 수 있음 (`[3, 2, 4]`, 6에서 3 + 3)
- `[3, 3]`, 6은 첫 3을 저장 → 두 번째 3에서 짝 3을 찾음 → `[0, 1]`
- 이중 for문 O(n²) → 해시 한 번 순회 O(n) (`in seen`이 O(1))
- 손으로 따라가기 (`[2, 7, 11, 15]`, 9): x=2 → 짝 7 없음 → `seen={2:0}` / x=7 → 짝 2 있음 → `[0, 1]`

## 헷갈렸던 개념 메모
- **이터레이터**: 한 번에 하나씩 꺼내 주는 물건. 한 번 꺼내면 다시 못 씀. `zip(...)`은 값이 아니라 이터레이터 → 보려면 `list(zip(...))`
- `x in 리스트`는 O(n), `x in set`은 O(1) → 반복 검사는 `set`으로 바꿔서
- **`most_common`**: "인기 순위표". `most_common(1)` → `[("사과", 3)]` = 가장 많이 나온 것 1개를 (이름, 횟수) 한 쌍으로. 큰 상자(list) 안에 작은 상자(tuple) → 꺼내려면 `[0]`을 두 번 (`[0][0]` 이름, `[0][1]` 횟수)
- **dict끼리 빼기**: 일반 dict는 `-`가 `TypeError`, `Counter`는 가능 (같은 키끼리 값을 빼고 0 이하는 사라짐). `Counter({"a":1,"b":2}) - Counter({"a":2})` → `Counter({'b': 2})`
- **`d[키] = 값`은 add 역할**: 키가 없으면 추가, 있으면 덮어써서 수정 (dict에는 `add`/`append`가 없음)
- **같은 키가 중복으로 들어오면 마지막 값이 덮어씀** (에러·경고 없음): `[(1,2,"A"), (1,2,"Z")]` → `{(1, 2): 'Z'}`. 전부 보관하려면 `d.setdefault(키, []).append(값)` → `{(1, 2): ['A', 'Z']}`. 문제에서 "중복이면 마지막만? 전부 모으기?" 조건을 꼭 확인
- **`enumerate(seq)`**: `(인덱스, 값)` 쌍을 하나씩 꺼내 줌. `for i, x in enumerate(arr):`로 **인덱스와 값 동시에** 얻음. 이터레이터라서 `list(enumerate(...))`로 감싸야 보임, `enumerate(seq, 1)`이면 1부터 시작. 두 수의 합처럼 값으로 찾고 **인덱스를 답으로** 낼 때 사용
