# Day 2 해시 · 함수 사용법 정리

> 모든 반환값은 실제로 실행해서 확인한 것. `사용법 → 반환` 순서.

## set

| 쓰는 법 | 반환 | 시간복잡도 | 메모 |
|---|---|---|---|
| `set(iterable)` | 중복 없는 새 `set` | O(n) | `set([1,2,3,2,1])` → `{1, 2, 3}`, `set("abca")` → `{'a','b','c'}` |
| `x in s` | `True` / `False` | **O(1)** | list의 `in`은 O(n) |
| `len(s)` | 개수 `int` | O(1) | 중복 제거 후 종류 수 |
| `s.add(x)` | `None` (s가 직접 바뀜) | O(1) | 이미 있으면 변화 없음 |
| `s.remove(x)` | `None` | O(1) | 없으면 `KeyError` |
| `s.discard(x)` | `None` | O(1) | 없어도 에러 없음 |
| `a \| b` / `a & b` / `a - b` | 새 `set` (합집합 / 교집합 / 차집합) | | `{1,2} \| {2,3}` → `{1,2,3}` |

- 순서가 없음 → 인덱싱(`s[0]`) 불가
- `add`/`remove`는 **`None`을 반환**: `s = s.add(1)` 하면 `s`가 `None`이 됨

## dict

| 쓰는 법 | 반환 | 메모 |
|---|---|---|
| `d[key]` | 값 | **없으면 `KeyError`** |
| `d.get(key)` | 값, 없으면 `None` | 에러 안 남 |
| `d.get(key, 기본값)` | 값, 없으면 기본값 | `d.get("z", 0)` → `0` |
| `d[key] = 값` | (반환 없음) | 없으면 추가, 있으면 수정 |
| `key in d` | `True` / `False` | **키**를 검사, O(1) |
| `d.pop(key)` | 지운 값 | 없으면 `KeyError` |
| `del d[key]` | (반환 없음) | |
| `d.keys()` / `d.values()` / `d.items()` | 키 / 값 / `(키, 값)` 모음 (뷰) | `list(...)`로 감싸야 list: `list(d.items())` → `[('a', 1), ('b', 2)]` |
| `d.setdefault(key, 기본값)` | 값 (없으면 기본값을 넣고 반환) | `d.setdefault("c", [])` → `[]`, 그룹핑에 유용 |

- **키는 immutable만**: `d[(1, 2)] = "A"` OK, `d[[1, 2]] = 1` → `TypeError: unhashable type: 'list'`
- `for k, v in d.items():` 로 키·값 동시에 순회
- **`d[키] = 값`은 add 역할**: 키가 없으면 추가, 있으면 덮어씀. dict에는 `add`/`append`가 없음 (있으면 `AttributeError`)
- **같은 키가 중복으로 들어오면 마지막 값이 덮어씀**: `d[(1,2)] = "A"` 후 `d[(1,2)] = "Z"` → `{(1, 2): 'Z'}` (에러 없음)
  - 전부 모으려면: `d.setdefault(키, []).append(값)` → `{(1, 2): ['A', 'Z']}`
- 좌표 `(x, y)`는 tuple이라 키로 가능: `board[(1, 2)]`, `board.get((9, 9), "빈칸")`, `(3, 4) in board`

  ```python
  for x, y, name in points:    # (x, y, 이름) tuple을 풀어서 받기 (언패킹)
      d[(x, y)] = name
  ```

## zip

| 쓰는 법 | 반환 | 예 |
|---|---|---|
| `zip(a, b)` | **zip 객체** (이터레이터) | 그대로 출력하면 `<zip object at 0x...>` |
| `list(zip(a, b))` | `(a값, b값)` tuple의 list | `list(zip([1,2],["a","b"]))` → `[(1, 'a'), (2, 'b')]` |
| `dict(zip(keys, values))` | dict | `dict(zip(["a","b"],[1,2]))` → `{'a': 1, 'b': 2}` |
| `zip(a, b, c)` | 3개도 가능 | `[(1,'a',True), (2,'b',False)]` |
| `zip(*pairs)` | 풀기(unzip) | `a, b = zip(*[(1,"a"),(2,"b")])` → `a=(1,2)`, `b=('a','b')` |

- **짧은 쪽에 맞춰 끊김**: `list(zip([1,2,3], ["a","b"]))` → `[(1,'a'), (2,'b')]` (3은 버려짐)
- **한 번만 쓸 수 있음**: `z = zip(...)` 후 `list(z)`를 두 번 하면 두 번째는 `[]`
- 순회에서 자주 씀: `for x, y in zip(a, b):`

## Counter (`from collections import Counter`)

| 쓰는 법 | 반환 | 예 (`c = Counter("hello")`) |
|---|---|---|
| `Counter(iterable)` | `Counter` (dict의 한 종류) | `Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})` |
| `c[key]` | 횟수 `int` | `c["l"]` → `2`, **없는 키 `c["z"]` → `0`** (에러 안 남) |
| `c.most_common(n)` | 많이 나온 순 `[(값, 횟수), ...]` n개 | `c.most_common(1)` → `[('l', 2)]` |
| `c.most_common()` | 전체를 많이 나온 순으로 | |
| `c.keys()` / `c.values()` | 키 / 횟수 모음 | `sum(c.values())` → 전체 개수 `5` |
| `c.elements()` | 횟수만큼 반복한 이터레이터 | `list(c.elements())` → `['h','e','l','l','o']` |
| `a - b` | 새 `Counter` (a에서 b를 뺌) | **0 이하는 사라짐** |
| `a + b` | 새 `Counter` (합침) | |
| `c.update(iterable)` | `None` (c가 직접 바뀜) | 횟수 누적 |

- **일반 `dict`는 `-`가 안 됨**: `{"a":1,"b":2} - {"a":1}` → `TypeError: unsupported operand type(s) for -: 'dict' and 'dict'`
- **`Counter`는 `-`가 됨** (dict를 물려받아 연산을 직접 정의해 둠): 같은 키끼리 값을 빼고, **결과가 0 이하면 사라짐**
  ```python
  Counter({"a": 1, "b": 2}) - Counter({"a": 1})   # Counter({'b': 2})
  Counter({"a": 1, "b": 2}) - Counter({"a": 2})   # Counter({'b': 2})  (a: 1-2=-1 → 사라짐, 에러 없음)
  Counter(a=1) - Counter(a=5)                     # Counter()          (빈 Counter)
  ```
  - 한쪽에만 있는 키는 그대로 남음
  - 일반 dict에서 키만 빼고 싶으면: `d1.keys() - d2.keys()` → `{'b'}` (set) / `{k: v for k, v in d1.items() if k not in d2}` → `{'b': 2}`
- `most_common(1)`은 **list 안의 tuple**이라 값만 쓰려면 `[0][0]`
- `most_common` 쓰는 법: `most_common()` 전부 / `most_common(2)` 상위 2개 → 항상 `[(값, 횟수), ...]` (많이 나온 순, 동점이면 먼저 나온 것). 빈 Counter면 `[]`이라 `[0][0]`은 `IndexError`
- 완주하지 못한 선수: `Counter(participant) - Counter(completion)` 하면 남은 1명만 남음 → `list(...)[0]`

## enumerate

| 쓰는 법 | 반환 | 예 |
|---|---|---|
| `enumerate(seq)` | `(인덱스, 값)` 이터레이터 | `list(enumerate(["x","y"]))` → `[(0,'x'), (1,'y')]` |
| `enumerate(seq, 1)` | 1부터 시작 | `[(1,'x'), (2,'y')]` |

- `enumerate`는 zip처럼 **이터레이터** → 값을 보려면 `list(...)`
- `for i, x in enumerate(arr):` → `i`는 인덱스, `x`는 값 (둘을 동시에 얻음, 언패킹)
- `for x in arr`은 값만, `for i in range(len(arr))`은 인덱스만 줌
- 두 수의 합처럼 값으로 찾고 **인덱스를 답으로** 낼 때 사용
